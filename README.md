# Educase Assignment

A responsive React application built using **React** and **Vite**. The app begins with a **Welcome page**, offering users the option to **Create an Account** or **Login**. It includes user onboarding forms, validation, and a profile display page.

## 🚀 Features

- ✅ **Welcome Page** with navigation to Create Account or Login  
- ✅ Separate forms for account creation and login  
- ✅ Onboarding form with **Full Name** and **Email** fields  
- ✅ Disabled submit button until valid input is provided  
- ✅ Inline form validation with helpful error messages  
- ✅ Styled with **Tailwind CSS**  
- ✅ **Profile page** displaying user details after login  
- ✅ Routing handled using **React Router DOM**  
- ✅ Fully responsive design using **CSS Flexbox**

## 🛠️ Tech Stack

- **React JS**
- **Vite**
- **Tailwind CSS**
- **React Router DOM**
- **JavaScript (ES6+)**
